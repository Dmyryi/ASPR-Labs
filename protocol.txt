=== Метод Гоморі ===

Згенерований протокол обчислення:

Постановка задачі:

Z = x1 + 4x2  ->  max

при обмеженнях:
2x1 + x2 <= 6
x1 + 3x2 <= 4

Цілі числа:
x1, x2

Перепишемо систему обмежень:

(-2,00) * X[1] + (-1,00) * X[2] + 6,00 ≥ 0
(-1,00) * X[1] + (-3,00) * X[2] + 4,00 ≥ 0

Вхідна симплекс-таблиця:

   =      -x1     -x2          1
-----------------------------
y1 =     2,00    1,00       6,00
y2 =     1,00    3,00       4,00
 Z =    -1,00   -4,00       0,00

Пошук опорного розв’язку:

Знайдено опорний розв’язок:
X = (0,00; 0,00)

Пошук оптимального розв’язку:

Розв’язувальний рядок:    y2
Розв’язувальний стовпець: -x2
Розв’язувальний елемент:  3,00

   =      -x1     -y2          1
-----------------------------
y1 =     1,67   -0,33       4,67
x2 =     0,33    0,33       1,33
 Z =     0,33    1,33       5,33

Знайдено оптимальний розв’язок:
X = (0,00; 1,33)
Max (Z) = 5,33

Знайдено розв’язок, у якому змінні мають дробову частину, максимальна дробова частина у змінної: x2 = 1,33

Складено додаткове обмеження:
s1 = 0,33 * x1 + 0,33 * y2 + (-0,33) ≥ 0

Симплекс-таблиця з новим обмеженням:

   =      -x1     -y2          1
-----------------------------
y1 =     1,67   -0,33       4,67
x2 =     0,33    0,33       1,33
s1 =    -0,33   -0,33      -0,33
 Z =     0,33    1,33       5,33

Пошук опорного розв’язку:

Розв’язувальний рядок:    s1
Розв’язувальний стовпець: -x1
Розв’язувальний елемент:  -0,33

   =      -s1     -y2          1
-----------------------------
y1 =     5,00   -2,00       3,00
x2 =     1,00   -0,00       1,00
x1 =    -3,00    1,00       1,00
 Z =     1,00    1,00       5,00

Знайдено опорний розв’язок:
X = (1,00; 1,00)

Пошук оптимального розв’язку:

Знайдено оптимальний розв’язок:
X = (1,00; 1,00)
Max (Z) = 5,00
